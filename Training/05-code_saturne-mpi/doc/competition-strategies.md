# Competition strategies

- Have a subgroup to focus on particular task
    - Suggestion to have two persons for each task
- Have git repository for all your work (scripts, documentation etc.)
- "Best is the enemy of the good"
    - Always try to first get something that just "works"
    - If competition rules allow multiple submissions, try to submit some
      results as early as possible
