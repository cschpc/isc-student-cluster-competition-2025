# SCC Prerequisite material

1. Read through the [Elements of Supercomputing](https://edukamu.fi/elements-of-supercomputing) course for the basics of supercomputing
2. Make a CSC user account and access the ISC training Mahti/Puhti/Lumi projects
  - Instructions for creating a user: [https://docs.csc.fi/accounts/how-to-add-members-to-project/](https://docs.csc.fi/accounts/how-to-add-members-to-project/)
  - If you face any issues on this step, please ask one of the advisors
3. Complete the self-learning course [CSC Computing environment](https://e-learn.csc.fi/course/view.php?id=76)
  - Topics 1-6 are essential, but aim to complete the whole course
  - Or conversely, the [Aalto Triton equivalent](https://scicomp.aalto.fi/triton/#tutorials)
4. (Optional) If you want to refresh your Linux skills, get acquainted with some of the basics through a CSC-provided [Linux basics Tutorial](https://docs.csc.fi/support/tutorials/env-guide/) (Chapters "Using Linux in command-line" and "Editing text and viewing images")
5. (Optional) Good [git tutorial](https://coderefinery.github.io/git-intro/)
