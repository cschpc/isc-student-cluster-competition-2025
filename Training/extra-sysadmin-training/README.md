# CSC Cloud resources

Repository for (extra) sysadmin training.

## Use cases

Team Lumikko has access to CSC's [cPouta](https://research.csc.fi/-/cpouta) platform.

The cPouta platform can be used for:

- Training on small clusters with root access
- Reserving clusters or nodes with different configurations 
- Preparing for system administration tasks
